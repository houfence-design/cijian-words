# 词间 · 英文写中文

考研英语中文释义默写，支持电脑与手机。

- 原词表6707词，分135单元；补充词表2148词，分45单元。
- 每个单元只有一种分类，每单元最多50词，不足50词的分类末尾独立保留。
- 逐词练习、整页默写、整单元提交、DeepSeek AI批改、错词复习、进度备份。
- AI接受中文近义表达，可选填全主要义项或任一主要词义。

## 密钥与进度

默认API密钥为空，由使用者在网页AI设置中输入自己的DeepSeek官方密钥。
密钥只发送到https://api.deepseek.com/chat/completions，不加入公开仓库、网址或练习备份。
默认只在当前页面打开期间保留；只有使用者主动勾选后才在本设备保存。

AI使用模型掌握的主要词义与原词表进行语义判断，没有实时查询牛津词典。存疑结果标记复核，并提供牛津查询入口。

练习进度保存在当前浏览器，跨设备请导出、导入备份。每台设备的密钥各自设置。
