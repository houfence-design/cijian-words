# 词间 · 双向词汇默写

在线练习：https://houfence-design.github.io/cijian-words/

支持电脑与手机的考研词汇练习。原有 6707 词分 135 单元，补充 2148 词分 45 单元；各分类独立，每单元最多 50 词，末尾不足 50 词直接保留。

- 英文写中文、中文写英文，均支持逐词与整页练习；两种方向分别保存答案、对错、错词与 AI 报告。
- 整组清空重写与一次撤销；累计记录和释义缓存保留。
- 主页面每个单元都有英中词义预览，可搜索并直接开始练习。
- 重点词收藏、AI 建议词一键加入重点；支持按分类分组复习重点词。
- 主页面支持中英文或单元号搜索。
- 每个单词都有独立中文释义卡，整组释义可搜索；不依赖填写或 AI 批改。
- AI 扩展释义可一次准备整组并缓存在本机，也可在设置中主动开启进入单元自动准备。只生成缺失词，修改答案与重新默写均保留缓存。
- 本地检查和异步 AI 更新保留当前单词位置、滚动位置及正在输入的焦点，避免跳回顶部。
- 部分作答即可提交 DeepSeek AI 批改；空白词单独列出。
- AI 结合本组当前作答及历史，分析掌握情况，给出优先复习词与建议。
- 每词记录练习、默写、正确、错误、待复核和查看释义次数，以及最近 60 条事件；同一轮相同答案本地后再交 AI 不重复计数。看过答案后的作答会标记辅助。
- 重新默写、错词复习、进度导入导出。旧进度兼容，旧版未知对错不补算。
- 默认邮箱登录/注册界面，支持邮箱验证和找回密码；同一浏览器自动保持登录，可随时退出这台设备。
- 使用同一邮箱登录手机和电脑，自动同步双向答案、每词练习历史、错词、重点词、AI 报告和释义缓存。断网先保存本机，联网后重试；多设备同时练习时合并计数，并为当前答案保留较新的修改。
- 账号之间独立保存本机缓存；初次登录时可以主动合并本机旧版离线进度。也可不登录、继续离线练习。

## 手机与电脑同步

1. 首次打开网站，点击注册，填写自己的邮箱和密码，按邮件完成邮箱验证。
2. 手机和电脑分别登录同一个词间账号。以后在相同浏览器中会保持登录，直到主动退出、清除站点数据或登录状态失效。
3. 查看账号处的“已同步”状态后，可在另一设备继续。页面打开时会自动检查更新，也可在“我的账号与同步”里立即同步。
4. 旧版记录先在原设备登录，再选择“合并原有进度”。原来的离线文件和在线网址属于不同浏览器存储来源；如需迁移离线文件中的旧记录，可先导出备份，再登录在线网站导入。

云端使用 Supabase Auth 和 Postgres。数据库按用户隔离，未登录不可读写，已登录用户只能读取自己的行；写入通过检查当前用户身份和版本号的原子 RPC。部署用的 publishable key 是公开客户端标识，不是管理员密钥。仓库没有数据库密码、service_role 或 Supabase secret key。

注册验证和密码重置依赖邮件投递。当前使用 Supabase 自带邮件服务，具有投递范围和频率限制；若扩展给更多用户，需在 Supabase 配置自己的 SMTP。请勿关闭邮箱验证来绕过邮件问题。

## 密钥、数据与释义来源

默认密钥为空，每位使用者自行在网页设置中输入自己的 DeepSeek 官方 API 密钥。密钥只发往 https://api.deepseek.com/chat/completions ，不会进入公开源码、网址或练习备份。默认仅保留于当前页面内存；主动勾选后才保存在本设备。

点击 AI 批改或分析时，仅发送本组词汇、当前答案、累计次数及最近 8 条记录。准备 AI 释义时只发送尚未缓存的本组词汇及参考释义，不需要作答，不增加默写次数。AI 功能使用使用者自己的 DeepSeek 余额。站点不提供共享密钥。DeepSeek 密钥不会写入同步数据库，各设备自行填写；登录账号后学习数据和释义缓存会自动同步。

词表释义和 AI 整理词义分别标明。AI 参考牛津常见主要义项，但没有接入牛津官方词典数据库或实时检索服务，不能视为牛津官方词条；不确定的批改标记需复核。释义在当前网页展示，没有词典跳转链接。

## 部署

index.html 自包含界面、代码与全部词汇。GitHub Pages 源为 main 分支根目录。离线本地检查可用，AI 功能需要联网及使用者自行输入密钥。

cloud-schema.sql 保存数据库表、RLS 和同步 RPC 的定义，便于备份和审查。前端内嵌官方 @supabase/supabase-js 2.102.0，保留 MIT 许可。
